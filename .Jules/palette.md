## 2024-05-24 - Accessibility improvements for icon-only buttons
**Learning:** In DevTools, React components using DOM factories for buttons (like `dom.button`) need to use standard hyphenated HTML attributes like `"aria-label"` instead of camelCase (`ariaLabel`). Additionally, for icon-only buttons, the convention is to assign the same localized text to both the `title` and `aria-label` attributes to ensure both sighted users and screen reader users understand the button's purpose.
**Action:** When creating or updating icon-only buttons in the DevTools UI using `dom.button()`, I will use hyphenated ARIA attributes and assign the localized text to both `title` and `aria-label`. I will extract the localization call (`getStr()`) to a single variable when possible to keep code DRY.
