## 2024-05-15 - ARIA attributes on icon-only buttons via Localized in Mozilla FluentReact
**Learning:** In Firefox DevTools UI components using `FluentReact.Localized`, when an icon-only button requires an `aria-label` or `title` for accessibility, those attributes MUST be defined in the `.ftl` file (using dot-notation like `.aria-label = Text`) and the `Localized` component MUST wrap the actual interactive `dom.button` element (not the inner `dom.img`). It must also explicitly enable these attributes by passing `attrs: { "aria-label": true, title: true }` so they are correctly applied to the button element.
**Action:** Always wrap the outer button with `Localized` and ensure attributes are explicitly enabled in `attrs` and defined in the `.ftl` when localizing icon-only buttons in Mozilla DevTools.
