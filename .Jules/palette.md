## 2024-10-24 - Accessible Labels in Firefox DevTools React Components
**Learning:** In Firefox DevTools React components (`devtools/client/responsive/components/*`), UI controls like `dom.button()` often rely solely on visual CSS classes (`devtools-button`) for presentation and omit essential screen reader labels. Using the `getStr` method from `resource://devtools/client/responsive/utils/l10n.js` to provide both `title` and `aria-label` ensures these controls are universally accessible and provide on-hover tooltips for sighted users.
**Action:** When adding missing labels to icon-only buttons in Mozilla React environments, always inject both `title` (for tooltips) and `aria-label` (for screen readers) mapped to localized strings in `.properties` files. Ensure you add `LOCALIZATION NOTE` comments above new properties strings.
