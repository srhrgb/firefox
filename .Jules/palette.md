## 2024-10-24 - Accessibility standards in Firefox DevTools
**Learning:** In Firefox DevTools components using React DOM factories, icon-only buttons often lack proper accessibility attributes by default. While they may have class names indicating their purpose (e.g., `animation-detail-close-button`), they are completely invisible to screen readers without explicitly adding `title` and `aria-label` attributes localized via `getStr` or similar helpers. Additionally, attempting to verify DevTools React UI changes via headless Playwright is fundamentally incompatible with the codebase's current environment.
**Action:** When adding or modifying interactive icon-only elements in Mozilla/Firefox projects, always manually check for and insert `title` and `aria-label` attributes using localized string properties. Furthermore, document environmental limitations regarding visual testing instead of attempting to force headless UI tests for DevTools.
