## 2024-08-04 - Localized ARIA Labels on Buttons
**Learning:** When using `FluentReact.Localized` on buttons with inner images, applying `.alt` directly to the `Localized` component but mapping it to an inner `<img>` is less accessible for interactive controls. Buttons should have their own `aria-label` and `title` attributes (for hover tooltips) applied directly via `Localized`, with the decorative inner `<img>` set to `alt=""` to avoid redundant screen reader announcements.
**Action:** When making icon-only buttons accessible in DevTools React components using `FluentReact.Localized`, update the `.ftl` file to define `.title` and `.aria-label`, enable them in `attrs: { title: true, "aria-label": true }` on the `Localized` wrapper, and set `alt=""` on the inner `img` child element.
