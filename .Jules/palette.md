## 2024-08-04 - ARIA labels for localized icon-only buttons
**Learning:** In Firefox DevTools React components (`aboutdebugging`), `FluentReact.Localized` handles attributes like `alt` on inner `dom.img` tags when configured in `attrs`. For icon-only buttons (`dom.button` wrapping a `dom.img`), screen readers often miss the `alt` text of inner images if the button itself lacks an `aria-label` or `title`. To make the button itself accessible, we should apply `title` (or `aria-label`) directly to the button via `Localized` by adding `.title` in the Fluent file and `title: true` in `attrs`.
**Action:** Always ensure icon-only buttons have an accessible label directly on the `button` element, even if the inner `img` has `alt` text. Use `Localized` with `title: true` (or `aria-label`) in `attrs` and add the corresponding attribute string to the `.ftl` file.
