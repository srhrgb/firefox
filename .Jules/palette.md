## 2024-05-19 - Accessible Toolbars
**Learning:** In Firefox DevTools toolbars (`devtools/client/*/components/Toolbar.js`), icon-only buttons often relied entirely on the `title` attribute for tooltips and accessibility. While `title` works for mouse users and some screen readers, explicitly providing `aria-label` matching the `title` text is a much more robust standard for screen readers and keyboard users. Additionally, in React components using `FluentReact.Localized`, enabling localizations for both requires passing an object to `attrs` (e.g., `attrs: { title: true, "aria-label": true }`) and updating the `.ftl` file.
**Action:** When creating or updating icon-only buttons in the Mozilla codebase, specifically DevTools, always pair the `title` attribute (for tooltips) with a corresponding `aria-label` attribute (for screen readers) utilizing existing localized strings. For `FluentReact.Localized` wrappers, ensure both attributes are enabled in the `attrs` prop.
