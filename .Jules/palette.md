## 2024-05-14 - Responsive Design Mode accessibility
**Learning:** Icon-only buttons in the Firefox DevTools Responsive Design Mode (like the rotate, screenshot, touch simulation, and device list edit/remove buttons) were relying solely on the `title` attribute for tooltips and accessibility. While `title` can act as a fallback, it is not consistently announced by all screen reader configurations when an explicit `aria-label` is missing, especially when the button is created via `dom.button({})`. Adding an `aria-label` alongside the `title` provides robust accessibility without changing the visual design.
**Action:** Always add explicit `aria-label` attributes to `dom.button` and other icon-only interactive elements in DevTools, typically using the same localized string as the `title` attribute, to ensure full screen reader support.
