## 2024-09-14 - Redundant tooltip duplication for accessibility
**Learning:** In Firefox DevTools React components using DOM factories (like `dom.button`), providing a `title` attribute correctly exposes a visible tooltip on hover, but does not inherently associate that text as the accessible name for icon-only buttons for screen readers relying purely on ARIA properties in some contexts. To ensure complete accessibility coverage for icon-only components that don't use `<FluentReact.Localized>`, the localized tooltip string must be manually duplicated into an `aria-label` attribute on the same element.
**Action:** When creating or modifying icon-only buttons in older or DOM-factory-based React components without explicit localization wrappers, proactively declare the localized string in a variable and apply it identically to both the `title` and `aria-label` attributes to ensure robust screen reader support.
