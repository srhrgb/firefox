## 2024-11-20 - Add ARIA Labels to Icon-Only Web Console Buttons
**Learning:** Found an accessibility issue pattern in Firefox DevTools where icon-only buttons (like those generated via React `dom.button()`) relied entirely on `title` attributes for tooltips but lacked `aria-label` attributes for screen readers. When localizing both `title` and `aria-label` with the same string in these environments, it is critical to extract the `getStr` or `getFormatStr` localization logic into variables at the top of the `render` method rather than wrapping component declarations in inline IIFEs, as doing so violates codebase idioms and creates unmaintainable patterns.
**Action:** When updating existing components to add `aria-label` where `title` already exists, always extract the localization logic into a distinct variable at the top of the functional scope, and pass that variable to both properties.
